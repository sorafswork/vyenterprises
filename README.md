# AI Prompt: Create a Premium Animated Website for VY Enterprises

Create a world-class, fully responsive, modern business website for **VY Enterprises**, an eco-friendly disposable products company based in **Tiruchirappalli, Tamil Nadu, India**. The website should feel premium, elegant, trustworthy, and environmentally conscious, with smooth animations and interactive storytelling similar to high-end product websites.

## Design Direction

Design a clean, luxury, nature-inspired interface using a minimal layout with plenty of whitespace, soft gradients, glassmorphism, rounded corners, premium typography, and subtle shadows.

Use a color palette inspired by nature:

* Primary: Forest Green (#1B5E20)
* Secondary: Light Green (#66BB6A)
* Accent: Leaf Green (#A5D6A7)
* Background: White (#FFFFFF)
* Neutral: Beige (#F5F5DC)
* Text: Charcoal (#212121)

The overall experience should communicate sustainability, innovation, professionalism, and trust.

## Animation Requirements

Implement cinematic, high-performance animations throughout the site.

Include:

* Smooth scrolling using Lenis
* GSAP scroll-trigger animations
* Framer Motion page transitions
* Floating eco elements (leaves, particles)
* Fade, slide, zoom, rotate, staggered animations
* Parallax scrolling backgrounds
* Animated counters
* Hover micro-interactions
* Smooth loading screen with company logo
* Scroll progress indicator
* Magnetic buttons
* Ripple click effects
* Cursor glow effect
* Animated section transitions
* Lazy-loaded animations for performance
* Mobile-friendly animations
* 60 FPS optimized interactions

Avoid excessive animation that impacts usability.
